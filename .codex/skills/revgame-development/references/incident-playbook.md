# 历史故障与验收对照

用于同类回归快速分流。先记录提交、运行环境、资源模式、操作顺序和第一个异常，按下表重跑最小可复现链路。历史报告只证明它记录的构建和输入，当前结论由本次证据给出。完整背景见 [项目开发复盘](../../../../RevGame_Client/文档/项目开发日志/RevGame项目开发复盘_2026-11-09.html)。

| 看到什么 | 先查哪一层 | 用什么证据结束排查 |
|---|---|---|
| 真实 AB 首次开 UI 白图，重进可能正常 | 确认 Bootstrap 先装配图集请求监听。检查 Sprite 引用和实际像素绑定，区分独立 Shader 采样纹理 | 冷启动首开与重入，核对图集唯一归属和引用归还。不要预载全部图集掩盖遗漏。[首次图集踩坑](../../../../RevGame_Client/文档/Bug踩坑记录/2026-10-19-UI图集像素未绑定-懒创建错过图集请求.md) |
| 棋子特效白剪影、低星攻击无反馈或退场残留 | 检查真实伤害事件与表现路径是否覆盖该星级，核对 MPB 的 `_MainTex`、图集局部 UV、池代次和 Tween 所有者 | 分别验规则提交与表现。核对低星/高星、近战/远程、正常结束与回收重入。[攻击反馈踩坑](../../../../RevGame_Client/文档/Bug踩坑记录/2026-10-19-低星棋子攻击反馈遗漏.html) |
| 领奖后出现旧章背景、过场提前收起 | 检查旧章节资源就绪标记何时清掉，以及同一事件触发的换章、准备和剧情等待顺序 | 等 `IsTransitioning=false`，断言章节、实际背景和可画状态。重复从真实领奖入口触发。[章节背景交割修复](https://github.com/Yokino337088/RevGame/commit/9eed179b) |
| 选了 Android 后 Editor 全屏粉色、材质名称仍对 | 区分 Build Target、实际图形 API、真实 AB 来源。检查 PC 主包、共享 Shader、映射及纹理绑定 | 原目标不变，用真实 PC AB 冷启动，检查实际像素。若追问为何拉取才坏，先比代码 blob 和包清单，再把本机偏好与候选触发条件分开。[AB 平台踩坑](../../../../RevGame_Client/文档/Bug踩坑记录/2026-11-09-EditorPlay误加载AndroidAB导致剧情粉屏.html) |
| Fantasy 握手或断线，协议号异常 | 区分端口占用、传输字节、版本与协议解码。先查首个失败点，按实际传输做回环或真实对手验证 | 同机探针、实际 Unity 客户端、端到端局与弱网恢复分别记录。当前 CS 的 KCP 入口见项目地图，早期 TCP 诊断作为历史证据。[围棋接入与握手记录](../../../../RevGame_Client/文档/进度同步/九路围棋开发交接-2026-11-06.md) |
| 外部 Agent HTTP 成功但反复非法落点、超时或迟到 | 区分响应解析、当前合法动作表、请求预算和局代次。用合法动作索引映射后仍走统一提交校验 | 核对请求与被接受棋谱、非法/超时/回退数和双方终局指纹。真实网络结论只适用对应采样，凭据不写入报告。[双 Agent 修复](../../../../RevGame_Client/文档/进度同步/DeepSeek真实双Agent修复-2026-11-07.md) |
| Android 出包、宽屏或凭据在真机与 Editor 行为不同 | 分开核对打包工具链、脚本后端、ABI、包平台、布局与实际存储平台 | 用发布目标独立验包或真机复测。Device Simulator 证据只覆盖布局。具体约定见 [Android 回归](android-build-and-mobile-ui.md)。 |

修复后记录“首因 → 改动 → 保持故障输入的复测 → 清理 → 验证边界”。遇到同类可复用的框架缺口，按版本锚点回框架源仓库处理。项目资源归属、业务门禁与测试接线留在 RevGame。

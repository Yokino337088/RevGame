# GPU、透明与Shader

先确定片元/采样/覆盖、CPU提交还是UI批次；DC/SetPass/贴图/有效GPU帧时分别记录，单个开关不证明收益。

| 技术 | 判断与验收 |
|---|---|
| Atlas+共享材质 | 同寿命/使用范围，相邻透明顺序；packed/页/AB无源图重复 |
| 动态合批 | 平台支持且CPU顶点变换合理；实际动态批次，不算已有开关新增收益 |
| UGUI合批 | 纹理/材质/Mask/层级；字形/遮罩/Canvas可打断同Atlas |
| GPU实例化 | 大量同Mesh/材质且CPU提交贵；实际instanced batches、矩阵/UV/颜色/帧/排序/裁剪/回退 |
| SRP Batcher | 真实SRP符合；不是一次Draw合所有，不擅改Built-in管线 |
| 静态合批 | 真静态；动态棋子/弹道/帧动画不用 |

SpriteRenderer写instancing关键字不等于实际实例化，不为降批次乱排透明/去描边。单Pass共享材质，参数块按必要时更新也可能影响批次需测；不每帧renderer.material克隆。

## 减少重复数学

保用户画质后识别静态几何、局部覆盖/远处尾项、重复噪声/指数/归一化；局部早退/静态场LUT/共享采样有新增纹理/带宽/精度代价，不把动态背景改静态图。

RevGame沼泽九口仍存在，先便宜delta覆盖/密度判断，远处才跳exp/normalize，范围内原式保留；边界余量是近似裁剪。256²周期数据代旧hash是固定种子新近似场，有外观差，硬件分支/带宽不同不保证每GPU快。

冰原固定3×3中心搜索生成512² RGBA：距离差/编码斜面xy/种子，[-12,12]映 `(p+12)/24`。像素中心、PNG行向、方向0～1编码/解码同源，量化/双线性非像素等价；边界/未绑定回原函数，雪/雾/寒潮/折射/原画继续实时。基础RGBA32两图约1.25MiB，不等总进程/驱动显存。

模式需适配实际Shader，不能复制案例阈值/图尺寸；生成器参数/输出开发路径明示，运行期不逐帧new数据/材质。

## UV与过绘

原图局部与Atlas绝对UV分开，局部→效果扭曲→限制安全范围→映回，防邻图/九宫格/黑边。UI的原图UV0与动画局部UV1不混。仅四边界用已确认GetOuterUV，不sprite.uv数组；同Sprite晚绑定UV会变，只对象引用检查不够。非Sprite背景/数据按真实采样不误打图集。

过绘看屏幕面积、透明层、字形描边、尾迹等子层；有限寿命/最小有效覆盖保画面。不新增GrabPass、逐棋RenderTexture、全屏模糊/重后处理掩原热点，除非需求明确且计代价。

## 验证

同内容CPU提交/GPU有效P50/P95、批次/SetPass/覆盖/纹理代价和完整轮次；停绘诊断恢复后验真改动。实际AB/目标平台编译与变体不只shader.isSupported；透明/颜色/量化、全屏/比例/安全区、0与多时间点/速度强度0/独立艺术流动、卡牌UV/翻转、Boss/围困动画与重入。GPU缺计时注明，截图好看不证明快百分之几。

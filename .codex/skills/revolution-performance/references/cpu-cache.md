# CPU、查询缓存与AI试算

按规则驱动/查询/预测评分/提交分别测量；显示帧与模型时钟分开，不将原冷却决策变每帧全盘AI。不从“棋子多”直接推ECS。

## 缓存稳定几何，评分仍实时

写清键、所有影响输出输入/版本、所有者、上限、结果可变性、嵌套/异步借用、失效/退出与命中计数。棋盘/实例私有，禁止实盘/试盘共用全局可变草稿。

RevGame射界actorId→有序坐标+拓扑/目标存活可见版本+Def+CanAttack+敌弓射程。Place/Move/Remove/Reset维护占格版本；隐藏/死亡/复活通知所属盘；冻结/锁死/免疫在CanAttack中核对，升星换Def失效。新增影响几何字段须补缓存输入，不只改原函数。

非致死HP变化不改几何，命中后仍读当前HP威胁/斩杀评分。缓存“能覆盖哪里”，不缓存“最该打谁”。复制坐标到调用者缓冲，调用者排序/删除不改条目；未入盘临时棋走原算法，防同Id污染实棋缓存。

候选与同分顺序属规则；不借优化改旧射线隐藏/致死未移除语义。10-30一度额外过滤导致一局积分/伤害不同，恢复后180回合逐字段一致，胜场相同不是等价。

## 索引与容器

- 热身份查询可用模型Id字典，但占格唯一真源保留；全部Place/Move/Remove/Reset和快照核对，重复Id拒绝、失败无部分登记、致死到撤盘保留原寿命。
- Count/Any直接累计/首命中早返，省只为整数/布尔建List；在盘/存活口径不变。缓存人数需覆盖所有变更入口。
- List/Queue/HashSet/二维距离数组预留并Clear保容量；本地池条目/棋群归还先清引用。容量预留不是规模上限，历史身份必须剔除。
- 热循环避免LINQ/ToArray/捕获排序/每次邻格数组，保留四邻顺序/大棋全外沿。值类型/接口枚举仍可能装箱/复制昂贵，实测而非假定免费。

## 独立深草稿

源盘拥有可复用试盘和Id→副本。撤旧占格→剔离场身份→身份不符新建/符合全字段覆盖→原顺序Place→复制驻眼Id→Evaluate。复用空间不复用旧结论。

覆盖所有可变状态：位置/Def、HP成长/倍率、气/眼/驻守/复活、护盾、隐藏/冻结/无敌/结束时间、行动进度/移动冷却等；只读图鉴共享，QueryBoard由试盘登记，不复制实盘归属。

候选恢复副本位置/重算，再Place/Move/重算评分；不省致死/补子/换位/眼破规则更新。真实棋只最终确认后提交。预测与正式结算共用纯公式但预测不扣盾血积分/派事件，别复制另一套数值。

友军/玩家/命中/整队原棋/副本/连接集合分职责，防嵌套覆盖外层遍历；不交异步长期保存。Reset清试盘/历史副本/名单引用，保容量；不无限保死棋。

## 棋群与路径

拓扑未变复用连通群；成员List兼作BFS队列，HashSet按Piece去重，大棋所有边沿四邻检查，根与左/右/下/上顺序保持。加气/免疫变动另影响规则评估，不能“位置没变”就不算气眼。

距离表/Queue复用，每次全格初始化，int.MaxValue不可达/0到目标边界；CanFit/障碍/受保护眼位保留。先筛明显不完整候选、所有门槛通过优选构图可早返，但不能跳安全校验。

## 数据布局与架构

业务命中率非L1/L2计数。连续数组、热冷字段拆分、批量访问可能改善局部性，没硬件证据不报百分比。先减少指针遍历/短命构造和必要数据工作集，验证顺序/身份/内存代价。

目标设备明确CPU规则大量独立运算持续超预算才做Jobs/Burst/ECS隔离原型；Unity对象主线程、不并行写实盘、原顺序提交。同规则/种子/对象/攻击/画质比较P95/GC/内存和逐字段结果。Piece变entity保留SpriteRenderer/TextMesh/UGUI/全屏Shader不会自动消表现成本，没固定48棋迁移门槛。

## 回归

缓存对原函数逐次比数量+顺序，普通掉血命中、隐藏/恢复、死亡到撤盘/复活、move/remove/reset、冻结/禁攻/免疫/升星/配置变化、重复Id/临时棋、随机盘、副本独立/复用/退出引用。固定盘100%不能推动态。

对照含同Evaluate工作量；48棋4800射界13.302→0.309ms、100含气眼快照4.643→3.575ms仅局部。新手注释说明失效遗漏如何变旧目标、错伤害或拆眼。

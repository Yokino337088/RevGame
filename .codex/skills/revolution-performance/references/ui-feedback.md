# UI、反馈、动画与分配

模型先结算，事件快照传Id/坐标/数值；延迟表现不再次扣血或积分。保既定画质/反馈密度，不删内容冒充速度。

## 变化才写UI

保持原观察节奏，先比较真实输入再ToString/Substring/拼文案/Text/SetActive。缓存是落屏收据不是业务数据：阶段/章回及后缀、人数/阵型/AI/增益/支援/日志、BossId/Hp/MaxHp/决死/擒王。

OnOpen/绑定/出池强制失效，同数值重开也画。钱包布局按尺寸/安全区，文字按余额/档位/攻防攻速；血条比比例+Sprite+enabled，演出曾隐藏不能只比比例。基础镜头布局可缓存，震动/特写逐帧叠加，不能缓存最终位置。

滚筒相同位值不重复几何，连续分数合并目标，每组必要Tween/Text，整行Mask替代逐位Mask须测批次。高频得分标脏定期刷盘，结算/离场/后台Flush；具体周期读项目配置不套案例2秒。

非交互图片关RaycastTarget；只有证据表明高频重建影响静态区域才拆Canvas并A/B。RevGame子Canvas未证收益已撤，不能默认越拆越快。

## 有界、公平的反馈

案例20文字/口号7、35弹道/16近战、待播70/81、每帧8数字/6弹道是项目契约，不推广数值。总量/每来源量/寿命/追赶有界，最久未显示者公平轮流，不让固定遍历饿死新棋。

同目标+伤害来源合并（普通/暴击/环境/技能不混色），值快照不持有死棋。过载只影响表现，真实伤害已入账。

最老8条一次扫描稳定插入固定八槽，严格小于时间保同时间戳次序；过期键先收集枚举后删，有预算才出队，失败停并保留其它。八遍变一遍只是扫描轮数，插入仍有成本，不是CPU必降87.5%。

在途请求也预约预算；旧阶段只能归池不能减新计数，冷失败释放本代预约/明确错误。切轮旧代次失效→停止→归池→清队列/预约→新阶段。格子整场寿命与阶段反馈代次分开，防清弹幕误拦格子加载。

## 文字与矩形

配置行Id+显示值做有界文案键（案例128FIFO），命中不用Replace/ToString；环槽淘汰先删字典旧键，游标合法循环。颜色/配置行表换失效，禁DomainReload新Play也复位；同表原地改内容需自己的失效契约。

池对象保上次内容/字号，相同不清再重写正文/描边；颜色/淡出独立。新字/字号/Font.textureRebuilt失效localBounds，静态字体事件销毁退订。

局部字形bounds→**文字子Renderer变换**→屏幕像素，缓存核对帧号/位置/缩放/旋转/相机view/projection/pixelRect，同帧Arrange改位置也重算；旋转/透视/多相机按真实约束验，不盲套正交假设。

每帧N字先取N矩形再两两比较；一次选位置共用其它字峰值/上浮预留矩形，固定候选按重叠面积+位移选最优。alpha=动画淡出×遮挡淡化；关系未变省色写但动画变化仍写，防旧字被重新点亮；透明/描边顺序保持。

## 闭包、Tween、池

已加载资源走RevPool热取，冷资源RevResManager异步；不是同步读冷AB。捕获式冷回调拆独立LoadCold方法，防编译器进热函数先建闭包。实例方法→Action也可能分配，棋盘结束/避让、HUD血条、每池对象Tween getter/setter/finish按实例创建一次，不静态留旧对象。

一对象一Tween统一0～1进度驱动位移/放大/振动/淡出，参数写本发字段。新发先Kill(false)再覆字段，旧setter不能读新轨迹。Finish先隐层/清句柄/摘旧回调，通知后Return，回池后不再访问；Tween池OnKill及时清引用，防误Kill被他人复用句柄。

分帧预热与实例化仍统计miss/活动/子Renderer；35弹道本体/轮廓/尾迹约105Renderer，活跃动画/透明像素仍贵。按需要Sequence，不每击堆Sequence/Timer。

## 验证

真实AB输入达到预算峰值不是只改常量；packed/共享材质/职业原画、极短/长轨迹、寿命/停输入/中断、公平/过期、合并来源/真实数字、移动缩放/重叠透明/边界/居中、阶段迟到回收。HUD准备→战斗→换轮→BossHP血线→关闭重开/安全区，不能手设UI预期假通过。行为通过再测UGUI/GC/帧时，语法和数量≠流畅。

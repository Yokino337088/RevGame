# 通用 CPU、GPU 与内存优化

先按相同场景、种子、画质、有效工作量和采样窗口复现。选一帧慢的画面以及正常对照，量规则、准备与提交、GPU 绘制和等待。怀疑内存时同时观察几次完整的加载与退出。**每次改变一项后，检查玩家规则、画面、操作等待和资源清理是否都成立。** [通用优化 Wiki](https://github.com/Yokino337088/RevGame/wiki/%E9%80%9A%E7%94%A8%E6%80%A7%E8%83%BD%E4%BC%98%E5%8C%96) · [测量与归因](measurement.md)

| 症状 | 先查的证据 | 命中后改什么 |
| --- | --- | --- |
| 每次攻击反复找棋、算射界、改同样的界面 | 同帧 CPU 标记的次数、时间、分配，区分业务、UI 准备和渲染提交 | 去掉重复查询、缓存稳定结果、变化才写 UI，把允许延期的表现分帧 |
| 相同棋局下，画得越大或特效层越多越慢 | 有效 GPU 用时、屏幕覆盖、透明叠层、采样和实际批次 | 缩小无用覆盖、提前拒绝完全挡住的背景、减少重复片元数学或采样 |
| 打几局后内存还在涨，或首次进场出现尖峰 | 同会话大厅基线、战斗峰值、退场稳态、持有者和分配栈 | 只装当前需要的资源、归还本局租约、有界复用并清理回池对象 |

## CPU 先量是哪一段重复在做

- 用局部标记量规则判断、索敌与试算、占格提交、HUD 和反馈准备。保留工作次数、每个单位耗时与整场帧间隔。对照同帧事件并区分线程等待，逐步缩到有名字的函数。固定条件下，缩减哪段就单测哪段。
- 给缓存列齐全部输入、版本、所有者、上限、失效和清理条件。稳定几何可缓存，当前生命值等实时时态继续读取。验移动、死亡、换位、复活和退场等全部影响入口，按原候选顺序比较输出和结算。没变的界面字段从比较真实输入开始省工，省下拼接与设置两段。
- 固定步负责实际扣血、索敌、占格和计分。把已结算的显示事件按预算安排，分开量工作耗时和显示等待。做架构改动前先确认规则 CPU 持续超预算，再用同规则的隔离原型判断 Jobs/Burst/ECS 是否划算。 [CPU 与缓存](cpu-cache.md) · [UI 与反馈](ui-feedback.md) · [CPU Wiki](https://github.com/Yokino337088/RevGame/wiki/CPU-%E5%B0%91%E5%81%9A%E9%87%8D%E5%A4%8D%E8%AE%A1%E7%AE%97)

## GPU 先量覆盖、画质与实际用时

- 固定相机、棋局和目标画面。用一项临时遮挡、范围或层数开关确认成本，再恢复完整内容验证正式方案。画面等价、绘制事件、GPU 用时、CPU 提交和整帧分别留证据。GPU 计数应有有效时间戳和样本数，读不到的记录为缺测。
- 全屏或多层透明先查过度绘制（同一像素反复绘制）、昂贵采样与重复数学。合并共享材质或图集时保留透明顺序，核对 Draw Calls、SetPass、实际实例化和带宽。深度预写只覆盖真实不透明范围，软边与缝继续按原路径绘制。比较背景与新增深度绘制的合计成本。 [GPU 与绘制](gpu-rendering.md) · [GPU Wiki](https://github.com/Yokino337088/RevGame/wiki/GPU-%E5%B0%91%E7%94%BB%E7%9C%8B%E4%B8%8D%E5%88%B0%E7%9A%84%E4%B8%9C%E8%A5%BF)

## 内存同时看分配、峰值与退场趋势

1. 同一版本、目标设备、画质与资源根集合下，记录大厅起点、加载或战斗的峰值，以及每次正式退出并等待相同时间后的稳态。冷启动和暖池分别记。重复进出，观察退场后增长能否解释为已确认的共享资源、暖池或分配器保留量。
2. 分开记录托管已用、分配量与 GC 停顿、Unity 原生已用和保留、纹理和材质、进程内存与 GPU 计数。包体压缩大小、原生纹理估算、进程常驻和 GPU 专用内存各有口径。用分配栈确认字符串、闭包、容器或字形的真实来源，用同帧计时确认 GC 停顿。
3. 定位谁仍持有资源。依次查域、在途请求、共享图集、对象池、Tween 和事件。退场先隔离迟到回调，再停异步与动画、回池、解除订阅、按所有权还租约。池容量应有限，空闲时按正常流程回收，避免在战斗热帧强制 GC 或全量卸载。资源引用归零可作为本次归还的证据，进程稳态要用重复采样另验。 [资源与生命周期](resources-lifecycle.md) · [内存 Wiki](https://github.com/Yokino337088/RevGame/wiki/%E5%86%85%E5%AD%98-%E6%9F%A5%E6%B8%85%E8%B0%81%E5%80%9F%E8%B0%81%E8%BF%98)

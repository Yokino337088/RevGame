01风格基准与交付规格（先读这个）

所有资源都必须满足这一节，否则进 Unity 会对不齐、大小不一、图集爆掉。

风格基准

  • 生活化：以扫帚、跑鞋、弹弓、茶壶、雨伞、闹钟等熟悉物件拟人化；不画专业设备，不用行话解释身份。
  • 作用一眼可见：跑鞋跑得快、弹弓打得远、雨伞护队友；棋子只画一个主动作和一个夸张表情。
  • 像素：棋子基准 32×32 像素（像素比 1:1），UI 允许 16~32px 细节，不做 3D 渲染、不做透视场景。
  • 配色：奶油白背景、暖棕色描边，天空蓝 / 活力橙 / 叶绿 / 危险红为状态色；最多 4 个主色 + 1 个高亮色。
  • 轮廓优先：缩到 32×32，遮住文字仍能认出物件；邀请至少 3 位非开发者测试，不能猜出用途则重画。

棋子单帧32×32 / 64×64 / 96×96

12制作优先级与分工

P0 · 没有就玩不了（约 1 周）

  • 战斗 UI 全套（§07）
  • 战斗状态标记（§04）
  • 棋子 1★ / 2★ 重绘（§02）
  • 棋盘 + 战斗事件图标（§06 / §08）
  • 三选一图标（§09）

P1 / P2 · 让它变好

  • 3★ / Boss 大棋子（§02 / §03）
  • 走法提示线框（§05）
  • 特效变体（§10，程序化）
  • 局外图鉴 / 主城 / 徽章（§11）
  • 攻击 / 受击 / 死亡骨骼动画（§02）

一句话：先做"看得见的规则"（标记 / HUD / 图标，量小作用大），再做"看得见的强度"（棋子 / Boss 重绘），最后做"看得见的爽"（特效 / 动画）。

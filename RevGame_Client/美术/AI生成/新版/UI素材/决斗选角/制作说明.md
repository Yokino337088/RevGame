# 决斗选角 UI 素材

- **DuelAtrium**：原创生成的红青裂隙底图，以斜切色块、网点和符纹形成双方对峙；选角和加载共用。
- **DuelEmber**：按项目绯焰的短紫黑发、红色战衣、黑色短夹克和双尖红枪生成的专用透明立绘。
- **DuelYaya**：原样复制用户指定的「鸦鸦待机摇_24帧/frame_00000.png」，保留原透明通道、法杖和小鸟。
- **DuelPlate、DuelButton、DuelSigil、DuelMeter**：金属九宫格、符印与进度条。魔法光轨由 Unity 共享 Shader 实时绘制。

两幅立绘供准备界面使用；战斗继续使用正式角色序列帧。

# 鸦鸦 · 决斗素材

白方鸦鸦有 51 张动画切片。普攻以用户提供的正面和全身侧面图共同校准；其余动作沿用全身侧面参考。侧身保留金发和黑羽衣装，两只靴口都落在膝盖上沿，露出膝上深色丝袜，保留金环花饰和金色鞋跟。肩鸦已从角色切片移除。

| 目录 | 内容 |
| --- | --- |
| 待机、移动、跳跃 | 8、12、4 张透明 PNG |
| 普攻 | 低扫、前弹踢、高位回旋踢，各 4 张 |
| 技能 | 鸦袭、掠羽、鸦宴，各 4 张 |
| 受击、倒地 | 2 张受击，1 张倒地 |
| 表情头像 | 原差分 28 待机、02 移动及施法和腿法起手收势、23 腿法蓄力与接触、19 受击、22 倒地 |
| 特效、音效 | 6 张透明特效图、9 段原创单声道 WAV |
| 源图 | 选用的 ImageGen 动作和特效原画 |

三段普攻采用压重心低扫、提膝前踢、转髋高位回旋踢。正面校准脸和服装，侧面校准较高的腰位、修长腿部和靴口。起手与收势采用原画 02 号的笑意，蓄力和第三张接触帧用 23 号的专注眼神，头像随角色实际贴图换帧。待机用 28、02 号并加入眨眼。移动采用半秒两步的十二帧循环，头颈微前倾，长发和黑羽衣随步伐轻摆。乌鸦术的起手、飞行、命中和声音分别由决斗播放层消费已确认的动作帧。

全身侧面图用于锁定角色比例，表情差分提供眉眼和嘴形。动作设计参考了视频中的低位扫击、动作高度区分和收势节拍。[鸡头大乱斗片段一](https://www.bilibili.com/video/BV1hLp363ERj/) · [片段二](https://www.bilibili.com/video/BV1xLYA6vEVh/?t=188) · [片段三](https://www.bilibili.com/video/BV1c7sf6AE65/?t=25) · [春丽官方角色指南](https://www.youtube.com/watch?v=seX6oUfwjII) · [花郎官方实机演示](https://www.youtube.com/watch?v=WAvVdlrHAKA)

Unity 使用 `Assets/GameRes/Art/Pvp/Duel/Arcade/Yaya` 的成品切片。角色帧采用 400×400 画布、居中轴心和共用落地线。场景和动画绑定由 `game.pvp.duel-sprites` 生成，`game.pvp.duel-atlas` 核对两席帧序、接触索引及 Sprite Atlas V2。白方特效共用 `YayaFeatherGlow` 材质，帧同步继续使用已有原生输入槽。

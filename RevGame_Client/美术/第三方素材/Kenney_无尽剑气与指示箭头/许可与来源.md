# Kenney 剑气与曲线箭头素材

获取日期：2026-11-03

剑气：Kenney Particle Pack，CC0。来源 https://opengameart.org/content/particle-pack-80-sprites （原作者 https://kenney.nl/assets/particle-pack）。保留trace_07、slash_03原图；横向剑气使用trace_07转向采样，Shader叠加刃芯和细束。

箭头：Kenney UI Pack，CC0。来源 https://opengameart.org/content/ui-pack （原作者 https://kenney.nl/assets/ui-pack）。使用arrow_basic_n，按有效Alpha范围裁切；箭头尖保持比例，曲线杆由UI网格生成。

导入配方：`game.endless.interaction` 通过 Unity API 装配现有 HUD/Arena 预制体；箭头尖与丝带纳入唯一 `EndlessCardArrow` Sprite Atlas V2。HUD底板保留原项目图片及九宫格配置，箭头属于变形网格，不使用底板Slice布局。

透明处理：粒子原图为黑色背景、完整Alpha。`EndlessThrustBlade` 和已有 `EndlessThrustTrail` 使用白色RGB与亮度Alpha，防止Shader画出黑色长方块；刃光转为横向，实际方向由攻击网格控制。它们为Shader采样的Default纹理，按项目规范不作为Sprite入图集。

动画参考：https://dotween.demigiant.com/documentation.php 。使用 `Ease.OutElastic` 弹性展开、`SetUpdate(true)` 无缩放时间和 `Ease.InBack` 收回。曲线采用标准三次贝塞尔算法与末端切线，DOTween只推进显示伸展量，不决定业务落格。

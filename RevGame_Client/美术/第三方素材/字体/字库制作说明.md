# Noto运行时字库制作

完整原件：NotoSansCJKsc-Bold.full.otf，来自原项目NotoSansCJKsc-Bold.otf，SHA256与字体精简清单中的sourceSha256一致。保留OFL许可和字体内版权信息。原件位于Unity Assets之外，不随AB/Player打包。

运行时字库保留NotoSansCJKsc-Bold.otf路径和GUID、Font材质及原字形。精简工具仅删除不使用字形，保留字形轮廓、水平宽度及关联排版功能。

在仓库根目录执行：

```powershell
python -m pip install -r tools/font-subset-requirements.txt
python tools/font-subset.py
python tools/font-subset.py --check
```

收集Assets/GameScripts（不含Generated）/GameRes/Scenes的C#、序列化资产和文本，解码Unity Unicode转义；同时读取配置表/*.xlsx文字。注释字符保守纳入，但注释装饰符号不作为必需显示字符。ASCII全保留，额外保留字符.txt供未来UI符号/动态文案增补。

构建门禁检查输入文件清单、各文件SHA、原字体/运行时字库SHA及Unity字符覆盖。新增/删除文案文件或编辑配置后必须重新生成；不放行旧字库，不静默删去原字体也不存在的必需符号。

当前字符集合只适用于现有游戏文本，不保证任意玩家输入、未来多语言或服务器未知文案。新增这些入口前必须调整字库策略。

## 四、使用注意（必读）

1. **尺寸不统一**，导入 Unity 后需要统一设置：
   - 实测分布：`100x100` ×19、`128x128` ×17、`64x64` ×6、`32x32` ×5、`16x16` ×8…
   - 建议：UI 类统一按九宫格 + Pixels Per Unit；棋盘单格设成和你现有棋盘一致的格宽
2. **面板/按钮类必须做成九宫格（9-slice）**，否则拉伸会变形。`panel_*`、`buttonLong_*`、`bar*_horizontalMid` 都是为此设计的
3. **风格不匹配是预期内的**：Kenney 是干净扁平风，和你现有的"低分辨率软阴影 + 硬黑描边"不一样。**这批只是功能占位，不是美术方向**
4. **叫吃脉冲 3 帧、占格虚影 2 份是同一张图复制**——占位用，正式版需要真动画
5. 图标有**黑/白两色**版本（game-icons 包里都有），需要哪个色直接换 `Black`/`White` 目录
6. 需要更多同类资源时，直接去 [kenney.nl/assets](https://kenney.nl/assets) 搜包名下载，全部 CC0

## 五、后续替换策略

先把 52 项全部接上跑通玩法，**替换时按这个顺序**（收益从高到低）：

1. **状态标记（15 个文件）** —— 量小、围棋内核可视化全靠它，替换收益最高
2. **战斗 UI 面板与按钮** —— 玩家停留时间最长的界面
3. **棋盘** —— 视觉占比最大
4. **事件/奖励图标** —— 数量多但单个面积小
5. **Boss 与特效** —— 最后做

替换时**文件名保持不变**，Unity 里的引用就不会断。

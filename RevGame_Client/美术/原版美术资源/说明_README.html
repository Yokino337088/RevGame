三、需要注意的几点

  • 44 张图未能反查到 prefab 引用：命名为 UI_编号N.png 或保留原中文名。它们没有被任何界面预制体直接引用， 可能是走代码动态加载、或已废弃的备用稿。明细见 重命名对照表.csv 中「备注」含「未能反查引用」的行。
  • 50 组内容完全重复的文件：源工程里本身就存在成套重复（例如 围棋\ui\ui an 与 正式图片\ui\ui an 是同一套图）。 归档全部保留、未做去重，重复关系记录在 CSV 的「内容哈希」列（同哈希即完全相同），由你决定留哪一份。
  • 史莱姆帧代号（f/s/d/ed）与部分特效文件名保留了原始代号：源图没有语义标注，避免臆造含义。
  • 05_音频/奶龙 是从外部引入的歌曲（非本作原创），若涉及商业化发行需要替换为原创或授权音乐。
  • 源工程零改动：Assets/ArtRes 下 435 个文件的数量、路径、内容均未变化。

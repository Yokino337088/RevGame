# 决斗音效来源

新增的打击采样来自 Kenney 的 [Impact Sounds 1.0](https://kenney.nl/assets/impact-sounds)，授权为 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。运行时使用单声道 44.1 kHz WAV。出招混入短促材质声，确认命中再播放拳击瞬态、金属或木质回声和衰减低频。原场景 WAV 保留同一路径和 GUID。

| 角色与等级 | 命中声使用的 Kenney 采样 |
|---|---|
| 绯焰普攻 | `impactPunch_medium_001`、`impactMetal_light_003` |
| 绯焰技能 | `impactPunch_heavy_001`、`impactMetal_medium_002` |
| 绯焰大招 | `impactPunch_heavy_004`、`impactMetal_heavy_002` |
| 鸦鸦普攻 | `impactPunch_medium_003`、`impactWood_light_004` |
| 鸦鸦技能 | `impactPunch_heavy_003`、`impactPlate_medium_003` |
| 鸦鸦大招 | `impactPunch_heavy_002`、`impactPlate_heavy_004` |

绯焰出招按普攻一、技能一、大招、技能二、普攻二、普攻三依次混入 `impactGeneric_light_003`、`impactMetal_light_004`、`impactMetal_medium_004`、`impactMetal_light_001`、`impactGeneric_light_001`、`impactMetal_light_002`。鸦鸦相同顺序使用 `impactGeneric_light_000`、`impactWood_light_001`、`impactPlate_light_001`、`impactPlate_light_003`、`impactGeneric_light_002`、`impactWood_light_002`。

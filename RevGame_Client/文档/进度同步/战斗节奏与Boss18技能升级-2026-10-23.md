# 战斗节奏与Boss18技能升级

2026-10-23 · Unity 2022.3.15f1c1 · RevGame · 当前功能与验收记录

## 已落地的规则

- 普通战与Boss战均不限时。删除超时胜利、按时间清敌、最后一子留1血；玩家全灭真实判负。每步先识别胜负，再处理支援，避免全灭后被援兵/炸弹反向救回。
- 战斗事件效果倍率为2，首次1.5秒、随后每2秒一次（旧间隔4秒），每轮最多1000次。原8事件保留，新增攻击、防御、攻速、生命4种事件，按Excel轮换。数量类援兵/补眼最多尝试两次，仍须合法落点和真实手牌。
- 新属性事件基准加成乘2后：攻击+30%、防御+30%、攻速+20%、生命上限+30%。本轮额外属性累计上限为500%（Combat.BuffCap）；防御+100%表示同样输入伤害约减半，并非免伤。生命改变保留当前血量比例，回合重置后重算；正常援军继承当前加成。
- 每15秒从可覆盖敌人的合法3×3范围随机抽取；无候选再全盘随机。预警1.5秒，格子依次间隔0.08秒，用DOTween上浮回落。范围内双方棋子受最大生命4%的原始伤害，仍经过真实护盾/减伤；大棋一次波动仅伤一次。
- 每24秒自动“能量巨大”，蓄力1.2秒，敌军全场最大生命5%原始伤害。池化炸弹、Shader扫描/裂纹、UI弹出抖动、相机衰减震动、低频爆炸音、移动平台振动接口已接入。
- 玩家近战每3.75秒尝试主动接敌，优先落单者与整块封气；远程在距离敌人不超过2格时后撤。试走使用独立深快照，提交仅走BoardModel.Move，保留己方眼阵，不以真实棋子试算。
- Boss必须血量≤20%且零气锁死才触发擒王；高于门槛包围只限制行动，不能直接胜利；直接击杀仍获胜。

## 配置与GM

源工作簿仍在`RevGame_Client/配置表`：本次修改战斗数值参数、增益与事件、战斗弹幕、Boss技能相关工作簿。通过框架导表工具正式导出14张表、200行，0错误/0警告；未手改生成代码/数据替代Excel。旧Battle.DurationSeconds等兼容参数不再参与战斗结束判断。

| 命令 | 语义 |
|---|---|
| `RevGame/战斗增益 Attack 30` | 战斗中本轮全队额外攻击+30% |
| `RevGame/战斗增益 Defense 30` | 战斗中本轮等效防御+30% |
| `RevGame/战斗增益 Haste 20` | 战斗中本轮额外攻速+20% |
| `RevGame/战斗增益 Vitality 30` | 战斗中本轮最大生命+30%，保留血量比例 |
| `RevGame/区域波动` | 真实随机选区、预警、逐格动画与伤害；拒绝重叠 |
| `RevGame/能量巨大` | 真实落弹与延迟结算；拒绝重叠 |
| `RevGame/战斗节奏` | 查询四属性比例、区域/炸弹次数与等待状态 |
| `RevGame/Boss技能 0` … `17` | 开发验收强制选招，仍检查合法目标 |

第二参数是“额外百分比”，不是“设置总倍率”。本轮命令受Combat.BuffCap约束，旧`RevGame/属性设置`开发工具仍保留。所有新增GM只在Editor/Development Build注册，注册注销对称，与正式服务共用规则。

## 调试与修复记录

1. 移除旧兜底事件后，启动文案校验仍要求Event_决胜支援：改为校验能量巨大，并覆盖所有真实事件枚举。
2. 真实Mono大额伤害被float舍入后转int溢出为0：统一扣血出口的准备减伤/防御中间值改double；保证致死伤害真正移除棋子。
3. Boss靠近GM只有一个距离参数，旧代码误读第二参数：修正到arg0；不改变技能合法目标限制。
4. 瞬移测试缺少更密集远端目标：准备期真实消费3张手牌造群；汲取使用既有压血GM满足残血条件。
5. 十字激光夹具目标在斜角：通过玩家同一点击换位入口移至轴线，不放宽技能命中范围。
6. 音效Failed事件包括正常Duplicated去重：分类统计，保留去重次数，其余错误仍失败；每招另验真实AudioSource播放。正式GameAudio避免把正常去重刷成告警。
7. 区域提示从已有勾号改为自有橙色条纹图；Tween终止时先解绑、恢复原始位置/缩放，防旧动画误伤复用对象。

首次失败、接线和夹具失败均保留在附件；最终验收以Play验收.txt首行“通过”为准。Unity MCP/RevMCP连接不可用时复用现有图形编辑器和官方Automation CLI，补有限动作的Editor验收入口；没有另开编辑器争用工程。

## 框架可行性结论

本轮继续以Revolution门面完成服务/配置/状态机/资源/声音/对象池/事件接线：Boss18招依然使用RevHeavyFSM，配置走框架导表与RevDataTableManager，声音走RevSound，视觉走RevPool与带生命周期的DOTween，GM只转发同一业务服务。没有改框架Core/Implementation内核；项目侧补的是几何、玩家战术、节奏规则、图集接线和有限测试入口。离线规则、图形Play及真实AB已形成分层证据。

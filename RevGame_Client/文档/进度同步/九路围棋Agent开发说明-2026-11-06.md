# 九路围棋 Agent 开发说明

日期：2026-11-06。目标：验证 Revolution 承载云端决策、共同命令提交和生命周期回收的可行性。

## 使用

进入九路围棋，在模式选择页或对局左侧打开“Agent设置”。填写 DeepSeek API Key 和模型名称（默认 deepseek-flash，可按供应商实际可用模型修改），选择“保存并授权云端调用”。棋局会发送至 DeepSeek 官方 HTTPS 接口并消耗该 Key 的额度。Key 通过 Windows 当前用户 DPAPI 加密后保存到本机 PlayerPrefs；应用启动时恢复 Key、模型和云端授权。明文 Key 不写入棋谱、联机服务器、测试报告或仓库。关闭云端并清除 Key 会删除本地密文。当前持久化覆盖 Windows，其它平台明确拒绝保存，不降级为明文。

本地人机：玩家手动执黑，白方自动使用云端策略；未授权时继续使用原有本地策略。玩家不能开启自己的托管。服务器匹配或局域网：进入实际棋局后，可在对局面板开启或停止“Agent托管”；仅控制本方座位，等待期间照常计时。停止托管使尚未返回的请求作废。

## 最小链路与职责

- PvpAgentSettings：运行时配置与授权校验，设置面板仅转发；PvpAgentSettingsStore 负责 DPAPI 密文保存/恢复。正式 Bootstrap 显式恢复，隔离棋局不自动读取玩家凭据。
- GoAgentPosition：持有每次决策的棋局指纹、序号与独立候选。完整克隆保留劫历史，所有合法落点加停一手都可选择，不限定为提示前三手。
- DeepSeekGoRequest：固定官方端点的 Chat Completions + JSON Output，关闭流式与思考模式，拒绝重定向；UnityWebRequest 异步操作由现有 PVP 域主线程轮询，不引入 Task/线程或 Python。输出必须完成且匹配候选。
- PvpService.Agent：每手一个请求，检查授权、控制座位、阶段、序号和指纹；切换设置、离开、断线等待或换盘时 Abort/Dispose。无效输出或网络错误本手回退本地策略，不无限重试付费请求。
- SubmitActor：玩家 Submit、电脑与云端共同的私有提交入口。身份、时间、预检、网络发送与棋谱提交均由游戏产生，模型不能提交超时、断线、伪造用时或控制对方。
- PvpLogic 继续归 PVP 域推进；RevUI/RevServices/RevTimer/RevPool 沿用原有契约。无需修改 Assets/Revolution 框架快照，也未更改 Fantasy 协议或把 Key 发给服务器。

## 首版能力边界

数子阶段 Agent 接受当前双方可见的死子方案，不自主反复标死子；玩家仍可修改死子并恢复对弈。首版不给模型认输权限。断网回退为现有启发式策略，不承诺专业围棋棋力。服务器目前仍为休闲棋谱中转架构，不能把相同指纹校验称为权威服务端反作弊。

网络请求工程超时上限20秒、输出上限128 token，属于通信保护参数；胜负时间仍使用导表的 GoClock 规则。设置仅支持 DeepSeek 官方供应商；Windows 本地加密持久化已实现，其它供应商和移动端/WebGL凭据保护后续单独推进。

## 验证入口

`dotnet run --project tools/PvpServiceChecks` 链接真实服务、规则与 Agent 调度，仅替换 HTTP、Unity和网络边界；不能当成真实云端或网络证据。

开发态运行期能力通过真实 `rev_discover` 获取：`pvp.agent-check`（隔离人机闭环/取消/回退）、`pvp.agent-fixture`（固定HTTP策略）、`pvp.agent-on/off`（正式托管入口/移除替身）、`pvp.lan-agent-begin` + `pvp.lan-game-state`（真实UTP两端自动结算）、现有 KCP 独立对手。替身只替换模型响应，棋局、网络、时钟和规则照常执行。正式包预编译排除这些入口。

验证结果与截图见同目录 HTML 报告。尚无用户真实Key，因此未验证付费DeepSeek请求、实际延迟、费用或棋力提升；不能用固定响应替身声称云端模型验证通过。

## 本地保存与品牌标识更新

设置中的“保存并授权云端调用”现在写入本机加密配置，重启自动恢复。DPAPI绑定当前Windows用户，不能把密文当作可跨用户/设备迁移的存档；也不防同用户恶意进程读取运行时内存。损坏记录不会开启云端，玩家可清除后重填。

默认API模型名继续使用官方 `deepseek-flash`，官方文档当前映射到2026-10-17发布的 `DeepSeek-V4.1-Flash-1017`。界面显示明确版本说明；这是供应商别名，不能承诺未来固定版本。Logo来自官方品牌素材ICON.svg，原件和来源保存在美术/第三方素材/DeepSeek，PNG等比渲染后通过独立PvpAgent Sprite Atlas V2随PVP设置加载。

测试使用独立PlayerPrefs槽和固定假Key，跨两次Play验证加密落盘与恢复，并检查损坏拒绝和删除；不读取/覆盖玩家正式存储项，不产生云端调用。早先报告中“仅本次会话”的说明为历史行为，以本次更新为准。

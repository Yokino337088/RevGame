# Agent超时与连接横幅根因

## 已确认的本地原因

每次服务器快照都将Status重写为“服务器已连接”，而Submit又将它写成“正在同步落子”；面板按字符串变化无条件发横幅，因此每手/同步都可能反复弹出。修复让事实快照不重写连接事件，并将普通对局状态留在HUD；连接成功不再弹横幅，匹配进场与真正异常仍可提示。

旧HTTP整次请求上限20秒、外层护栏25秒，在尚未收到完整非流式响应时就会中止；旧catch又合并了认证、余额、限流、网络、非法JSON等失败。它不能证明用户每次失败都是供应商慢。没有旧请求的HTTP分类和阶段计时，不能追溯断言每次失败的网络根因。

## GitHub研究与采用

- OpenAI Agents SDK：模型调用超时、错误标准化、受控重试、取消与重放边界。阅读 https://github.com/openai/openai-agents-python/blob/main/src/agents/run_internal/model_retry.py 及 docs/running_agents.md 。
- Microsoft AutoGen：CancellationToken把取消传播给在途操作。阅读 https://github.com/microsoft/autogen/blob/main/python/packages/autogen-core/src/autogen_core/_cancellation_token.py 。
- DeepSeek官方说明：https://api-docs.deepseek.com/quick_start/rate_limit/ 。非流式请求等待期间可返回空行保活，不能把仍在等待的连接等同于无效响应。

保留项目C#与RevLogic生命周期，不安装Python Agent运行时。模型选择、合法性验证、动作提交分离；沿用代次/棋谱指纹拒绝迟到结果和Dispose取消。借鉴错误归类与独立预算，而不是套用通用SDK的长时间自动重试，避免重复计费。

## 修改与行为

- HTTP工程上限65秒；本手应用预算上限60秒，并收紧到当前显示剩余时长的80%，预留落子/同步余量。实际胜负仍由导表GoClock规则决定。
- 分离认证失败、余额不足、429限流、供应商5xx、请求参数、DNS、TLS/证书、连接失败、HTTP超时、截断响应、非法动作等本地白名单原因；不输出响应正文/标头或Key。
- 记录最后失败类别与用时；连续3次失败后冷却60秒，冷却期间透明显示使用本地策略。修改配置会解除冷却，成功响应重置失败计数。单次请求不盲目付费重试。
- 精简重复提示语，仍保留全部合法候选，未将模型偷偷限制为启发式前三手。
- 增加只编译Player脚本的项目Editor动作，匹配目标Windows Mono Development和REV_AUTOMATION配置；不会调用BuildPlayer，不使用编辑器DLL替换游戏。

RevGame 实现与框架验证报告

更新及验证日期：2026-10-17。Unity 2022.3.15f1c1。当前交付包含此前 A–C3 闭环，以及新版美术、慢节奏、六张手牌、全盘重摆、DOTween、弹幕 Excel、回合表现清理和手机横屏安全区适配。

当前结论

Revolution 的公开门面能够支撑本次原型的流程、规则、UI、资源、对象池、音频、导表和开发验收。主界面、六章选关、布阵、自动战斗、结算与奖励形成闭环。这证明编辑器原型可行；尚未证明 AB、真机、小游戏或正式数值环境可发行。

本轮通过原 Revolution.ExcelTool 导出并运行时读取弹幕配置。正式基础生命、攻击、敌方阵容和平衡表仍等待用户提供，不能把这部分也写成已完成。章节解锁目前仅保存在本次运行中。

远程攻击 我方远程默认两倍频率，约 0.625 秒一次，由 BattleTuning 配置。可以原地攻击全盘最近敌人；每发重查目标，前一发击败目标后不会继续打空对象。
守阵与敌方 AI 我方自动战斗始终原地守阵，一眼/两眼不会被自动移动拆散。敌方仅射程内无目标时、每五秒最多靠近一次；有目标只攻击。滑步最多一格，马步保留原走法。
升星与眼阵 三同名同星合成；3★ 占 2×2，放不下时保留材料。已有眼的守子不作为自动合成材料，援军不会填掉眼位。“瞬移潮”改为“守阵回气”。
攻击与伤害 攻击者头顶出现对应棋种口号，弹道抵达后显示实际扣血数字。数字冲击放大、黑描边、分通道上浮淡出；顶排文字限制在屏幕内。口号控制同棋密度，伤害和弹道仍逐次展示。
升级与支援提示 UI 大字条播放滑入、放大回弹、停留和淡出。升至 2★/3★均有独立文案；支援事件显示标题和效果说明。全部走 Excel 配置。
多次支援与获胜辅助 首次支援 3.75 秒，之后间隔五秒，每回合上限 12 次。轻松模式保护最后一颗我方至少 1 血，45 秒使用真实决胜伤害清剩敌人；HUD 明示辅助，不冒充自然平衡。
原有闭环 Boss 主将血条与擒王、章节三选一、职业加成、同章残局保留、换章清盘、返回主界面等保留。基础配置共六章各 11 回合。
音频 RevSound 播放原有 BGM 与原型短音效；已确认播放状态和播放位置递增，未宣称人工听音评估。

Excel 到运行时的真实链路

工作簿：战斗弹幕配置.xlsx。

工作表 用途
BattleText 21 行：九种攻击口号、两级升星、伤害数字、八种支援和决胜支援。字段包含 Id、Text、Detail、ColorHex、FontSize、Duration、PeakScale。
BattleTuning 一行 PlayerRangedActionsPerTick，当前值 2。表示每个 1.25 秒基准周期可进行的我方远程攻击次数。
#配置说明 给改表同学的字段、占位符和导出说明；# 开头不参与导出。

前 3 行分别是字段名、类型和中文注释，第 4 行开始数据。升级支持 {piece}、{star}，伤害支持 {damage}。字段说明也会进入生成代码的中文注释。

通过 Unity MCP 调用原框架 ExcelTableBuilder / ExcelExportPlanner，再使用 Revolution.Editor.ExcelTool.RevExcelCI.Export() 复导验证。实际日志为 2 张表、22 条数据、4 个文件未变，并非手写相似生成物。

生成文件：

  • Assets/GameScripts/Generated/BattleDataStructures.cs
  • Assets/GameScripts/Generated/BattleDataTables.cs
  • Assets/GameRes/Data/BattleText.txt
  • Assets/GameRes/Data/BattleTuning.txt

Unity 菜单：Revolution.Tools/配置表/导表工具。本机源已设置，修改文案或数值后用“快速导出（仅数据，不生成代码）”；改字段后全量导出。共享输出设置保存在 ProjectSettings/RevExcelToolSettings.asset，个人 Excel 源记录在 UserSettings；换机器应重新选择工作簿。

GameBootstrap 通过 RevDataTableManager.LoadAsync<T>() 加载两表并检查必需编号、颜色和参数范围，配置有效后才开放主界面。GameTextConfig 只查询已加载数据，不直接读 Excel 或磁盘文件，不静默回退到另一套硬编码文案。退出卸载表。

DOTween 与框架对象池

官方免费版 DOTween 1.3.045，位于 Assets/Plugins/Demigiant/DOTween，含 DLL、XML、九个官方 Modules、LICENSE 和来源说明。固定来源提交 bfb02b05551a45204352dc43bdc15b882147891a，不包含 Pro。用户明确要求引入它用于表现。

BattleEffectView 的伤害、攻击口号、弹道，以及 BattleEventNoticeView 的升级/增益提示通过 RevPool.GetAsync<T>() / Return() 复用。每个零件保存自己的 Tween，回池、停用或销毁时 Kill(false)，不调用全局 KillAll。UI 提示独立容器放在 Canvas 下，重置局部 Z，避免池对象离开画布平面而不可见。HUD 关闭归还活动提示并销毁该池；异步回调核对批次，过期结果不得在大厅补播。

CardItem 本身是六个常驻槽位，不为每次刷新重新实例化。翻牌只改显示，服务先一次性提交新手牌；动画中断不会扣第二次牌，也不会丢失已经生成的新牌。BoardView 的棋盘加载批次与短命效果批次分开，清弹幕不能误取消81个棋盘格的加载。

新同学操作入口

  1. 打开工程的 Assets/Scenes/SampleScene.unity，按 Play，进入“开始闯关”及第一章。
  2. 左侧选牌，再点任意空格落子；点己方棋子再点空格可免费重摆；右侧刷新剩余手牌，点“准备完毕”开战。
  3. 改弹幕时编辑配置表，再使用原框架导表菜单。不要手改 Generated 或 Data 的生成结果。
  4. 非 Play 运行 RevGame.Editor.GameRuleChecks.Run()。Play 在主界面运行 RevGame.Editor.GameFeelChecks.BeginPoolCheck()，至少等待四秒再查看 LastResult。
  5. GM 顺序：RevGame/打开选关 → RevGame/进入战斗 1。常用动作：刷新手牌、点棋盘 X Y、载入验收场景 merge/large-merge/events/boss/reward/round10、落首张牌、开始战斗、战斗事件 7、返回主界面。检查返回的 Success 和 Message。
  6. 资源需重新装配时，通过 MCP 调用项目 Editor 生成器，最后调用 GameFeelBuilder.Apply()，避免早期布局覆盖新节点。运行游戏不需要执行生成器。

2026-10-18 补记：六牌列距与手机全屏

六张手牌继续使用左侧两列三行布局。卡槽位置统一由 GameBattleLayout.HandCard 计算，水平列间距取“左侧栏宽度的 16%”与“安全区高度的 6%”中较小值，纵向间距仍为安全区高度的 1.2%。卡片尺寸同时受两列总宽和三行总高约束，拉开两列时不会把手牌推入棋盘或挤出侧栏。

右侧深灰留空已通过 Unity MCP 量测定位：Note20Ultra 模拟设备物理尺寸为 3088×1440，非全屏时 SimulatorInsets=(0,0,0,168)，游戏可渲染尺寸变为 2920×1440。上轮验收调用 SetResolution(..., false) 后留下了系统导航栏区域；指定背景图片与既有等比覆盖算法本身没有缺口。此次不更换背景，启动入口 GameBootstrap.Awake 在 Android/Editor 下通过 UnityEngine.Device.Screen.fullScreen = true 明确进入手机全屏，并已使用 SetResolution(0, 0, FullScreenMode.FullScreenWindow) 恢复模拟器默认全屏分辨率。

后续验收若临时改变分辨率，必须保持全屏，并在 finally 中恢复默认分辨率及全屏状态，避免测试修改继续影响人工游玩。交互元素仍使用安全区布局，背景覆盖完整渲染区域。

本轮 Unity 编译未发现 error CS，经 MCP 执行 GameLayoutChecks.Run() 返回 737 条通过，覆盖 5 种尺寸与各 3 种安全区，检查六牌边界、列间距、1.08 倍放大所需横向空间及重复计算稳定性。Play 实际截图在 3088×1440 和 1920×1080 下均显示背景铺到右边缘，MCP 量测 SimulatorInsets=(0,0,0,0)、全屏模式为 FullScreenWindow。使用全屏模式切换渲染尺寸后，已恢复设备默认 3088×1440；GM 刷新手牌成功，六槽实际布局及翻牌动画回位已由 MCP 量测通过：六槽均活动，所有牌均已结束翻转、缩放恢复为 1、旋转恢复为初始状态，场景为 1 个相机与 1 个 Canvas。前文 570 条规则与 136 条回合表现为上一轮历史，本轮未重跑；本轮也未覆盖 Android/iOS 真机验收。

# 直接打开 RevGame Unity 工程

双击 `Start_Unity.cmd`。首次运行输入本机 `Unity.exe` 路径，或包含 `Editor/Unity.exe` 的Unity安装目录；以后直接双击打开工程，无需Unity Hub。

配置保存在同目录 `unity-launcher.local.json`，只属于本机，不提交仓库。工程位置从启动器目录推导，移动仓库无需改工程路径。项目当前使用Unity 2022.3.15f1c1，请选择对应版本。

重新配置：

```cmd
Start_Unity.cmd -Configure
```

只检查配置、不启动Unity：

```cmd
Start_Unity.cmd -CheckOnly
```

支持输入带空格/中文的路径以及Unity安装目录、Editor目录、Unity.exe三种形式。保存路径失效时会提示重新配置；工程已经打开时不会重复启动。直接按回车可取消首次配置。

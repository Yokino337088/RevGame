# 九路围棋规则离线检查

运行：

```powershell
dotnet run --project tools/PvpRulesChecks/PvpRulesChecks.csproj -c Release
```

该工程直接链接 `Assets/GameScripts/Pvp/Core` 的真实源码，不复制规则实现到服务端，不需要启动 Unity 或云服务器。构建缓存不入库。控制台断言失败会以非零退出，不能用 `dotnet test` 的“零个测试成功”代替这里的执行结果。

规则事实归 `GoCore`：固定 9×9、黑先、共享气、整块提子、禁自杀、精确位置超级劫。位置超级劫保存完整 162 位棋面键；公开 Zobrist 哈希用于快速对账，规则不会依赖哈希碰撞概率。`TryApply` 是网络/回放的统一入口，所有失败保持棋盘、回合、序号与历史不变。

双方连续停一手进入数子阶段。死子整块标记是共享草稿，修改会清除双方确认；双方确认同一份方案后才按中国面积法结算。有争议可恢复对弈，超级劫历史仍然保留。辅助眼形只提示局部形状，不自动宣布活棋或死棋。提子数是显示统计，不重复加入面积分。

贴目由外部配置按半目整数传入：15 表示 7.5 目，即 3.75 子。黑白面积差减去 7.5 目才是最终目差；不能直接减 3.75。`GoScore.DifferenceHalfPoints` 是带符号的半目差，正数黑胜，负数白胜。

`GoClock` 不读取系统时间。调用方只在每条已提交命令处传入整手思考时长；显示使用 `PeekRemaining`，不会因为刷新而重复扣时间。读秒每耗尽完整周期扣一次，落子后最后未耗尽周期回满。计时、贴目、建议次数都由游戏的 Excel 配置输入，规则源码不提供隐藏默认值。

本轮实际执行（2026-11-06，.NET 10）：**9,993,477 个断言通过**，500 局固定种子测试，46,521 条合法动作、113,143 次非法尝试。除双实例同源对拍外，还使用测试目录内的独立慢速参考算法（全盘扫描、字符串历史）核对每步合法性与棋面，避免两个客户端恰好同算错而通过。覆盖提子、自杀、劫、双停一手、死子协商、续弈、面积中立点、眼形、建议无副作用、完整重放、主时限与读秒边界、非法快照原子拒绝。

该证据只证明纯规则与时钟。Unity 生命周期、画面可读性、真实 AB 首开、网络配对、两个真实进程与手机表现应另行验证。

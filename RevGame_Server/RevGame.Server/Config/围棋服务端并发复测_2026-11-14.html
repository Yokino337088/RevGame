跨进程和决斗

固定配置下，Gate 和 Battle 分别由 Fantasy Release 模式的两个 OS 进程承载。40 个 KCP 客户端命中四个内网 Battle Scene，共 20 局、640 条操作，房间分配为 5 / 5 / 5 / 5，换 Socket 恢复与离席通过。该轮端到端 P99 为 1137.26 ms。公网服务的尾延迟和节点故障恢复仍待验证。

TCP 探针通过兼容快照、棋力匹配和单节点 128 活跃房间上限。真实 KCP 的双席决斗在第 79 帧正常终局并完成同帧指纹核对。千人测试的工作量是围棋，决斗并发容量仍待单独测量。探针和本轮服务实例均通过脚本的清理路径退出。
